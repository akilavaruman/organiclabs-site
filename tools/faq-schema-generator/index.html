      2026 Update
      
Is FAQ Schema Still Worth Using in 2026?

      
The dropdown is gone. The reason to write good FAQs isn't.

      
What changed. In August 2023, Google limited FAQ rich results to well-known government and health sites. In May 2026, Google removed them for everyone. Search Console's FAQ reporting ends in June 2026, and API support ends in August 2026. Google lists these changes in its Search Central changelog.

      
What didn't change. FAQPage is still valid Schema.org markup. It still describes your questions and answers to machines. Google's FAQPage documentation still says the markup must match content that is visible on the page.

      
Keep or add FAQ schema when the page has a real, visible FAQ section written for that page.

      
Remove it when the questions aren't visible on the page, or a plugin already outputs the same markup.

      
Many FAQ generators still promise the dropdown in search results. That promise is out of date. Judge your FAQs by whether they answer real questions clearly, because that is what readers and AI tools use.

      
"If a tool still promises the FAQ dropdown, check its date."

    


    

      Research
      
Does FAQ Schema Help You Get Cited by AI?

      
AI tools quote answers, not markup.

      
The correlation. In our 19-study meta-analysis, structured, answer-first content (FAQs, schema, clear blocks) had the strongest link to AI citation of any signal we reviewed (0.81).

      
The controlled test. Ahrefs tracked 1,885 pages that added JSON-LD against matched controls. Adding schema produced no meaningful citation lift in AI Overviews, AI Mode or ChatGPT.

      
Our read. The visible Q&A does the work. A clear question as a heading, with a direct answer under it, is easy for any model to lift. The markup labels that content for machines. So write the answers first, then wrap them.

      
The overlooked part. Some accordion widgets load FAQ content with JavaScript. The Vercel and MERJ crawl study found major AI crawlers don't run JavaScript, so they may never see that content. This generator outputs plain HTML, including the accordion option, so your answers are in the page source.

    


    

      Writing
      
How to Write FAQ Answers AI Tools Can Quote

      
If the first sentence can stand alone, the answer is quotable.

      
These five rules match the clarity check in the tool.

      
    
        
  1. Answer in the first sentence. Skip "Great question" and "It depends". State the answer, then explain.
    2. 
        
  2. Keep it to 30 to 60 words. Long enough to be useful, short enough to quote whole.
    3. 
        
  3. Name the subject. Write "Acme's SOC 2 module..." instead of "It...". A quoted answer loses the question around it.
    4. 
        
  4. Stick to one idea per answer. Link to a fuller page for detail.
    5. 
        
  5. Use questions buyers really ask. Pull them from sales calls, support tickets and People Also Ask, not from what you wish they asked.
    6. 
      

      
Here is a typical B2B SaaS pricing answer, before and after:

      

        
Before
How much does Acme cost?
Great question! At Acme, we believe in flexible, best-in-class pricing that scales with your business. It depends on your needs, so reach out to our team to learn more about the plan that's right for you.

        
After
How much does Acme cost?
Acme costs $49 per user per month on the Team plan, billed annually. The Enterprise plan adds SSO and audit logs, with custom pricing for 50+ users. Both plans include a 14-day free trial.

      

      
The first version has no number, no subject and two filler phrases. The second answers in eight words and stays accurate when quoted on its own.

      Example
      
FAQ Schema Example (FAQPage JSON-LD)

      
One FAQPage per page, matching what readers see.

      
FAQ schema uses one FAQPage block per page, with "@context" set to https://schema.org. Its mainEntity is an array of Question items. Each Question has a name (the question) and an acceptedAnswer of type Answer, with the answer in text. Here are two questions in JSON-LD, followed by the matching visible HTML.


<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "How much does Acme cost?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Acme costs $49 per user per month on the Team plan, billed annually. Enterprise pricing is custom for 50+ users."
      }
    },
    {
      "@type": "Question",
      "name": "Does Acme integrate with Salesforce?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "Acme integrates with Salesforce through a native two-way sync. Setup takes about 10 minutes from Settings > Integrations."
      }
    }
  ]
}
</script>


<section class="faq">
  <h2>Frequently asked questions</h2>
  <h3>How much does Acme cost?</h3>
  <p>Acme costs $49 per user per month on the Team plan, billed annually. Enterprise pricing is custom for 50+ users.</p>
  <h3>Does Acme integrate with Salesforce?</h3>
  <p>Acme integrates with Salesforce through a native two-way sync. Setup takes about 10 minutes from Settings &gt; Integrations.</p>
</section>

    


    

      Install
      
How to Add FAQ Schema to Your Site

      
One source of markup per page. Never two.

      
Add the visible FAQ to the page body and the JSON-LD to the same page. Check first whether your CMS or a plugin already outputs FAQ markup. Two FAQPage blocks on one page send mixed signals.

      

        
PlatformHow to add it

        
          
WordPressUse a plugin FAQ block (Yoast or Rank Math) or a Custom HTML block with our HTML and JSON-LD. Never both: plugin blocks already add the markup.

          
WebflowAdd the HTML in an Embed element, and the JSON-LD in Page settings > Custom code (before </body> or in the head).

          
HubSpotAdd the HTML in a rich text or custom module, and the JSON-LD in the page's Advanced options > head HTML.

          
Next.js / ReactRender the FAQ and the JSON-LD script server-side in the page, not in a client-only component.

        
      

      
Then run the page through the schema validator or the Check a page tab above to confirm there is exactly one FAQPage block.

    


    

      Mistakes
      
Common FAQ Schema Mistakes

      
Most FAQ schema problems are content problems.

      
The markup is simple to get right. What goes wrong is usually the content around it: missing, duplicated, hidden behind JavaScript, or written as marketing copy.

      

        
MistakeFix

        
          
Markup with no visible FAQ on the pageAdd the visible Q&A or remove the markup

          
Two FAQPage blocks (plugin + manual)Keep one source

          
FAQ loaded only by JavaScriptRender the HTML and JSON-LD server-side

          
Marketing copy as "answers"Answer the question in the first sentence

          
Same FAQ pasted on many pagesWrite page-specific questions

          
Expecting a rich resultThere isn't one now; judge FAQs by clarity and engagement

        
      

      
Write FAQs for the reader first. The markup follows.

    


    

      FAQs
      
FAQs

      
This FAQ and its FAQPage markup were made with this generator.

      
What is FAQ schema?
FAQ schema (FAQPage structured data) is JSON-LD that labels a page's questions and answers so machines can read them. It describes a visible FAQ section; it doesn't replace it.

      
Is FAQ schema dead?
The Google rich result is. Google limited FAQ rich results in 2023 and removed them for all sites in May 2026. FAQPage is still valid Schema.org markup and still helps machines understand your Q&A.

      
Does FAQ schema help with AI Overviews or ChatGPT?
Not on its own. A controlled Ahrefs study found adding schema didn't lift AI citations. Clear, answer-first Q&A on the page is what tools quote; the markup labels it.

      
Should I remove existing FAQ schema?
Keep it if the page shows the same questions and answers. Remove it if the Q&A isn't visible, or if a plugin already outputs the same markup.

      
Does FAQ schema improve rankings?
No. It's not a ranking factor, and it no longer creates a rich result in Google.

      
How many questions should an FAQ section have?
Usually 3 to 8 on product or blog pages; more on dedicated FAQ pages. Only include questions buyers actually ask.

      
How long should FAQ answers be?
30 to 60 words, with the direct answer in the first sentence. Link to a fuller page for detail.

      
Can I use FAQ schema on every page?
Only on pages with a real, visible FAQ that's specific to that page. Copy-pasted FAQs across many pages add little.

      
Is this FAQ schema generator free?
Yes. No sign-up. Drafts, HTML and JSON-LD are all free.
