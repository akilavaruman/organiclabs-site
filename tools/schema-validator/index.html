What It Checks

What This Schema Markup Validator Checks

Most validators answer one question. This one answers four.

A schema markup validator reads the structured data on your page and tells you whether it is correct. "Correct" means four different things. The two official tools each cover only part of the job.

First, this structured data validator checks syntax and Schema.org vocabulary. That makes it a JSON-LD validator for developers who paste raw snippets. Second, it applies Google's rules for required and recommended properties. Third, it tells you whether Google still shows that rich result at all. Fourth, it shows whether your markup sits in the server HTML, which is the version AI crawlers read.

It also flags the problems that are hard to spot by reading code: relative URLs, non-ISO dates, duplicate Organization blocks with different values, and markup values that don't appear on the visible page.

How To

How to Validate Schema Markup in 3 Steps

Fix errors first. Then confirm with Google.

  1. Paste a URL or your JSON-LD and click Validate schema. Use the URL tab for live pages and the Paste code tab for snippets you haven't shipped yet.
  2. Read the summary, then open any block with errors. Fix errors first, because they block rich results. Then work through warnings, which usually mean missing recommended fields.
  3. Re-validate, then confirm in Google's Rich Results Test before you publish. Google's test is the authority on eligibility. This tool tells you what to fix. Google's tool tells you whether it now qualifies.
Comparison

Schema Validator vs Google Rich Results Test vs Schema.org Validator

Use the right tool for the question you're asking.

Google retired its Structured Data Testing Tool in 2021. The job was split in two. The Schema.org Validator took over vocabulary checks. The Rich Results Test took over Google features. People still search for the old structured data testing tool because neither replacement does the whole job.

That split causes the most common confusion in schema work. A page can pass the Schema.org Validator and fail the Rich Results Test. A page can also pass Google's test for one type while carrying a second type Google ignores completely. Neither tool explains the gap.

Rich Results in 2026

Which Schema Types Still Get Rich Results in 2026?

Valid isn't the same as visible.

Google has been retiring rich result types in waves. HowTo and FAQ were cut back in August 2023. Seven more types were phased out from June 2025. Further removals followed in late 2025 and 2026, listed in Google's Search Central changelog.

When a type is retired, nothing breaks. Your markup stays valid Schema.org. The rich result simply stops appearing. That is the single biggest reason for "zero errors but no rich result".

Research

Does Schema Markup Help You Get Cited by AI?

Schema travels with the pages AI cites. It doesn't make AI cite them.

You have probably been told that schema gets you cited by ChatGPT. The evidence points two ways, so here are both sides.

The correlation

Ahrefs analysed 6 million URLs and found AI-cited pages were almost three times more likely to carry JSON-LD than pages that weren't cited. In our 19-study meta-analysis, structured, answer-first content (FAQs, schema, clear blocks) had the strongest link to AI citation of any signal we measured (0.81).

The controlled test

Ahrefs then tracked 1,885 pages that added JSON-LD against 4,000 matched controls from August 2025 to March 2026. Adding schema produced no meaningful citation lift in AI Overviews, AI Mode or ChatGPT.

Our read. Well-built pages tend to have schema, so the two show up together. The structure on the page (clear headings, direct answers, tables) is what models lift into answers. Schema does a different job. It tells machines who you are and what the page is about.

The overlooked part. Many sites inject schema with a plugin, a tag manager or a JavaScript framework. Google renders JavaScript, so the markup looks fine in Google's tools. AI crawlers are a different story. The Vercel and MERJ crawl study found GPTBot, ClaudeBot and PerplexityBot don't execute JavaScript. If your schema only exists after JavaScript runs, those crawlers never see it. That is why this tool shows raw vs rendered for every block.

What to do.

  • Keep your schema accurate and in the server HTML.
  • Prioritise Organization with sameAs and author markup for entity clarity.
  • Put the effort meant to earn citations into structured, answer-first content.

For sameAs, list the profiles that confirm your identity: LinkedIn, Crunchbase, G2 and Wikidata if you have an entry. For authors, mark up a Person with a url to their bio page and sameAs links to their profiles. Only add aggregateRating if the rating is shown on the page.

FAQs

FAQs

These FAQs carry FAQPage markup. It's still valid Schema.org and describes the Q&A on this page, even though Google no longer shows FAQ rich results.

What is a schema markup validator?

A schema markup validator checks the structured data on a page (usually JSON-LD) for syntax errors, Schema.org vocabulary errors and missing properties. This one also checks Google's required fields, current rich result status and whether AI crawlers can see the markup.

How do I check if my schema markup is working?

Paste the page URL into the validator, fix any errors, then confirm in Google's Rich Results Test. After publishing, watch the rich result reports in Search Console.

What's the difference between this tool and Google's Rich Results Test?

Google's test only checks the rich result types Google supports. This validator checks all Schema.org types, flags types Google no longer shows, and compares raw HTML with the rendered page. Use Google's test as the final word on eligibility.

Why is my schema valid but not showing a rich result?

The most common reasons: Google no longer shows that type (HowTo, FAQ and several others), a required property is missing, the markup doesn't match visible content, or Google simply chose not to show it. Valid markup makes a page eligible, not guaranteed.

Does schema markup help with ChatGPT and AI search?

It helps machines understand your brand and page, but a controlled Ahrefs study found adding schema alone didn't increase AI citations. Keep it accurate and in the server HTML, and focus on clear, answer-first content.

Can AI crawlers read schema added by JavaScript or Google Tag Manager?

Often not. A Vercel and MERJ study found major AI crawlers such as GPTBot and ClaudeBot don't execute JavaScript. Put JSON-LD in the server-rendered HTML to be safe.

Should I remove FAQ schema now that FAQ rich results are gone?

You don't have to. FAQPage is still valid Schema.org and can describe real Q&A on the page. Remove it if the questions aren't visible on the page.

Which schema format should I use?

JSON-LD. Google recommends it, and it keeps structured data separate from your HTML so template changes are less likely to break it.

Is this schema checker free?

Yes. No sign-up. You can email yourself the report if you want to keep it.
