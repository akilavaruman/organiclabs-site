    Key Takeaways

      Basics

      What Is llms.txt? (And Is It llm.txt?)

      A short, curated map of your site, written for AI tools.

      llms.txt is a markdown file that sits at yoursite.com/llms.txt. It lists your most important pages, each with a one-line description. AI tools can read it to find the pages that matter without crawling the whole site.

      Jeremy Howard proposed the format in September 2024 at llmstxt.org. It is a community proposal, not a standard. No standards body such as the W3C or IETF has adopted it, and no major AI provider has committed to reading it.

      People often search for llm.txt. The file is llms.txt, plural. Tools that look for it request /llms.txt, so a file named llm.txt won't be found.

      Research

      Who Actually Reads llms.txt? What the Data Says

      Publishing the file is easy. Getting anything to read it is the hard part.

      Most llms.txt generators promise AI citations and "future-proofing". Server logs tell a different story. When researchers count actual requests to /llms.txt, they find very few, and most of those come from generic bots rather than AI search crawlers.

      Last checked: 19 November 2026.

      Where it does help. Developer docs and API references. Coding agents and AI developer tools are the readers most likely to look for the file. If you run a docs site, an llms.txt (and llms-full.txt) is a reasonable courtesy to them.

      Format

      llms.txt Format, With an Example

      One title, one summary, a few sections of links.

      The llmstxt.org spec is short. Follow these rules and any tool that reads the file can parse it:

      • Start with exactly one H1: your site or product name.
      • Add a blockquote with a one-line summary of what you do.
      • Group links under H2 sections, such as Docs, Product or Research.
      • Write each link as - [Title](URL): description.
      • Keep descriptions under about 15 words, and use absolute URLs.
      • Put low-priority links in a final section called Optional. Tools with limited context can skip it.

      llms-full.txt

      What Is llms-full.txt?

      The index is llms.txt. The book is llms-full.txt.

      llms-full.txt is a single file that holds the full text of your key pages in markdown. It's mainly useful for documentation, where a coding agent can load your whole docs set in one request. Include only pages you are happy for AI tools to ingest whole. The file can get large, so keep marketing pages out. Many generators charge for llms-full.txt. Ours includes it free.

      Install

      How to Add llms.txt to Your Website

      The file must live at the root of your domain.

      Tools look for the file at exactly yoursite.com/llms.txt. Serve it as plain text (text/plain or text/markdown) and make sure it returns a 200 status without a login or bot challenge. Some platforms make root files easy. Others need a workaround, and we say so plainly.

      PlatformHow to add llms.txt
      WordPressUpload to the site root via SFTP or your host's file manager. Some SEO plugins, such as Yoast, can generate one for you.
      ShopifyNo direct root uploads. Upload the file under Content > Files, then add a URL redirect from /llms.txt, or use an app that serves it.
      WebflowNo root file uploads. Host the file as an asset and redirect /llms.txt to it, or serve it through a proxy such as a Cloudflare Worker.
      Next.jsPut llms.txt in the /public folder and redeploy.
      NuxtPut llms.txt in the /public folder and redeploy.
      FramerRoot files aren't supported directly. Use a redirect or a proxy in front of the site.
      Static site / cPanelUpload to public_html (or your web root).

      A redirect works for most tools, but a file served directly at the root is safer. Then run the checker to confirm it's live.

      Logs

      How to Tell If Anything Is Reading Your llms.txt

      Your logs know. The hype doesn't.

      Open your server logs or CDN analytics (Cloudflare, Vercel, Netlify or your host). Filter requests to the path /llms.txt. Then group them by user agent, so you can see which tools made each request. Look for AI agents and assistants, such as ChatGPT-User or Claude-User, and coding tools. Review the numbers once a month.

      Expect very little. Most llms.txt files get no fetches at all in a given month. Treat any agent traffic as a bonus, not a target. If you want AI visibility, the requests that matter are crawlers fetching your actual pages.

      FAQs

      FAQs

      What is an llms.txt file?

      A markdown file at the root of your site (yoursite.com/llms.txt) that gives AI tools a short, curated list of your most important pages with one-line descriptions. It's a community proposal from 2024, not an official standard.

      Is it llm.txt or llms.txt?

      llms.txt, plural. "llm.txt" is a common misspelling; AI tools that look for the file request /llms.txt.

      Does llms.txt help me get cited by ChatGPT or Google AI Overviews?

      There's no evidence it does. Google says its search products don't use it, and server-log studies show AI search crawlers rarely fetch it. It's most useful for developer docs read by coding agents.

      Do AI crawlers read llms.txt?

      Rarely. Ahrefs found 97% of llms.txt files across 137K domains got zero fetches in May 2026, and OtterlyAI logged 84 llms.txt requests out of 62,100+ AI bot visits.

      Is this llms.txt generator free?

      Yes. No sign-up, up to 500 pages, and llms-full.txt included.

      How do I check if my llms.txt is valid?

      Use the Check tab: it tests the format against the llmstxt.org spec, checks every link, confirms the file is reachable, and tests whether AI crawlers can access your site.

      What's the difference between llms.txt and llms-full.txt?

      llms.txt is a short index of links. llms-full.txt contains the full text of those pages in one file, mainly for documentation.

      How often should I update llms.txt?

      When you add or retire important pages, or about every quarter. Re-run the checker after updates.

      Should I block AI crawlers or allow them?

      Allow the search crawlers (OAI-SearchBot, PerplexityBot, Claude-SearchBot) if you want to appear in AI answers. Training crawlers (GPTBot, ClaudeBot, Google-Extended) are a separate choice.
